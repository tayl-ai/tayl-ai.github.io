FAQ

Straight answers, including the awkward ones

What Tayl does, what it does not do yet, and where your data goes. If a question is not answered here, ask us through the contact form.
Ask a question
Is my data uploaded to Tayl?
No. Tayl has no hosted backend for user data. Business data lives on your Windows PC in a local SQLite database. The website itself collects only the email you submit for the download or contact form. See the privacy policy.
Which LLMs can I use?
You choose a cloud LLM or a local LLM on first run and supply your own API key or model details. Tayl does not bundle an API key. The exact list of supported providers is being finalised.
What does a cloud LLM see?
With a cloud provider, the content of your queries is sent to the provider you chose, using your key. That provider's terms and privacy policy apply. Your local database and uploaded documents are not hosted by Tayl, but the query content does leave your machine.
Do I need an account?
No website account is needed. Accounts and settings live in the desktop app. The email form is only used to provide the download link and, if you opt in, product updates.
Is Tayl open source?
No. Tayl is proprietary, closed-source software. The software is licensed under the terms in the Terms of Use.
Which operating system does Tayl run on?
Tayl is a Windows desktop application installed from an .exe. It runs on the user's PC. Supported Windows versions and minimum hardware are listed on the download page when confirmed.
Does Tayl work offline?
The app and its local data run on your PC. A cloud LLM needs an internet connection to answer questions. A local LLM can allow question answering without sending query content to a cloud provider, subject to your hardware.
What documents can I upload?
PDF, images, CSV, XLSX and DOCX files.
Can Tayl write to my tools?
Execution is currently Coming soon. Connectors start read-only. Tayl does not write to a connected tool unless the Execution stage is available and you explicitly approve an action. See how it works for the current status of every stage.
How do I delete my data?
Uninstall Tayl and delete its local data folder and SQLite database to remove the local copy. To remove an email you submitted on this website, use the contact form and ask for deletion. The documentation walks through the local removal.
Is my data encrypted?
We do not make encryption claims beyond what is documented. The security page states what is true about the architecture and what is not claimed. If encryption details matter to your decision, treat them as unconfirmed until the owner publishes them.
Is Tayl SOC 2, ISO 27001, GDPR or HIPAA certified?
No such certification or compliance claim is made on this site. The product is local-first, but that is an architecture description, not a compliance certification. Read Security and data.
How much does Tayl cost?
Pricing has not been announced. This site does not claim that Tayl is free, and no price is shown until one is published.
How do I report a bug or a security issue?
Use the contact form. Choose Report a problem for a bug or Other for a security report, and include enough detail to reproduce it. Do not send passwords, API keys or confidential documents. Security reports are also described on the security page.
