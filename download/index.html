Windows SmartScreen

A new installer may show a warning

Windows may show a SmartScreen warning for a new or unsigned installer. That does not automatically mean the file is unsafe, but you should only proceed if you downloaded it from this page and the checksum matches.

Choose More info and then Run anyway only after verifying the file. If you are unsure, stop and contact us through the contact form. Do not bypass a warning for a file from an unknown source.

Verify the download

Check the SHA-256 checksum

After downloading, open PowerShell and run the command below. Compare the result with the SHA-256 value in the release details. If they differ, do not run the installer.

Get-FileHash .\path\to\downloaded-installer.exe -Algorithm SHA256

A published checksum is only useful when it is published separately from the installer. Always compare against the value shown on this page.

Install

What happens after the download

The exact wording of the installer and first-run screens may differ from this outline.

  1. Download the installer from this page using the email form.
  2. Open the downloaded .exe file.
  3. Follow the installer prompts and launch Tayl.
  4. On first run, choose a cloud or local LLM and add the API key or model details it asks for.
  5. Connect a tool or upload a document, then ask a question.

You will need your own API key for the cloud LLM you choose, or a local model configured in the app. Tayl does not supply an API key for you.
